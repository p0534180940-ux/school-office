🔑 הרשמה עם קוד קופון – מדריך למנהל

בזכות מערכת ההרשמה אפשר לתת את המערכת לאנשים נוספים: רק מי שקיבל ממך קוד קופון יכול להירשם. הכניסה עצמה נעשית עם קוד חד-פעמי שנשלח למייל, בלי סיסמאות.

השרת הוא Google Apps Script בחשבון ה-Google שלך. המיילים יוצאים מהחשבון שלך, ורשימת המשתמשים והקופונים נשמרת בגיליון שלך. אין עלות.

1

יוצרים גיליון ופותחים את עורך הסקריפט

פותחים sheets.new ומשנים את השם ל"שרת מערכת המזכירות". אחר כך בתפריט: תוספים ← Apps Script.

2

מדביקים את הקוד

מוחקים את כל מה שכתוב ב-Code.gs, מדביקים את הקוד ושומרים (Ctrl+S):

אחר כך: ⚙️ הגדרות הפרויקט. בשדה אזור זמן בוחרים Jerusalem.

3

התקנה ראשונית ובדיקת מייל

חוזרים לגיליון ומרעננים (F5). מופיע תפריט 🔑 מערכת הרשמה. לוחצים התקנה ראשונית ומאשרים הרשאות.

⚠ תופיע הודעה ש-"Google לא אימתה את האפליקציה". זה תקין, כי זו אפליקציה שלך. לוחצים מתקדם, אחר כך מעבר אל … (לא בטוח), ובסוף אישור.

אחר כך לוחצים שליחת מייל בדיקה אליי. אם הגיע מייל עם קוד, החיבור למייל תקין.

4

מפרסמים את השרת

  • ב-Apps Script לוחצים פריסה ← פריסה חדשה ← ⚙️ ← אפליקציית אינטרנט.
  • בשדה "הפעלה בתור" בוחרים אני. בשדה "למי יש גישה" בוחרים כל אחד, כדי שהאתר יוכל לפנות לשרת. המידע עצמו מוגן בקודים.
  • לוחצים פריסה ומעתיקים את הקישור של אפליקציית האינטרנט. הוא מתחיל ב-https://script.google.com/macros/s/
5

מחברים את האתר לשרת

שולחים לי את הקישור, ואני מכניס אותו לקובץ config.js באתר. אפשר גם לבד: בגיטהאב פותחים את config.js, לוחצים ✏️, מדביקים את הקישור בין המירכאות של API_URL, ושומרים (Commit).

✔ מהרגע הזה, מי שנכנס לאתר רואה מסך כניסה. מי שאין לו קופון לא יכול להירשם.

לא חובה: קריאה אוטומטית של טפסים סרוקים

במודול רישום התלמידים המערכת יכולה לקרוא טופס בכתב יד ולמלא את השדות לבד. באתר הרגיל זה דורש מפתח API של Anthropic, בתשלום לפי שימוש, בערך כמה אגורות לטופס. פותחים חשבון ב-console.anthropic.com, יוצרים מפתח, ובגיליון בוחרים 🔑 מערכת הרשמה ← הגדרת מפתח לקריאת טפסים.

בלי מפתח, מקלידים את פרטי הטופס מול התמונה הסרוקה. כל השאר עובד כרגיל.
