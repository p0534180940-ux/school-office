# מערכת המזכירות

אתר אחד, עם כניסה בקוד קופון, שמרכז שלושה כלים למזכירות בית ספר.

| קובץ | מה זה |
| --- | --- |
| `index.html` | דף ראשי (תפריט) |
| `login.html` | הרשמה עם קוד קופון, וכניסה עם קוד חד-פעמי במייל |
| `register.html` | רישום תלמידים: קליטת טפסים סרוקים, רשימות, נוכחות, אישורים |
| `labels.html` | מדבקות שמות: דף משותף לכיתה, כל מספר מדבקות בדף, PDF |
| `tasks-spec.html`, `tasks-setup.html` | מערכת המשימות והתזכורות (Apps Script בחשבון המזכיר) |
| `spec.html` | אפיון מאוחד |
| `admin-setup.html` | מדריך למנהל: התקנת שרת ההרשמה וניהול קופונים |
| `config.js` | הגדרות: כתובת שרת ההרשמה (`API_URL`) ושם המערכת |
| `auth.js` | בדיקת כניסה וסרגל ניווט משותף לכל הדפים |
| `server/Server.gs` | שרת ההרשמה (Google Apps Script) |
| `apps-script/` | מערכת המשימות (Google Apps Script) |
| `netlify.toml` | הגדרות לאתר הבדיקה ב-Netlify |

כל עוד `API_URL` ריק, האתר פתוח לכולם (מצב הקמה). אחרי שמכניסים את הקישור של השרת, נדרשת כניסה.
