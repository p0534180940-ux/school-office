# כלים למזכירות בית הספר

אתר סטטי (GitHub Pages) עם שני כלים:

| קובץ | מה זה |
| --- | --- |
| `index.html` | דף הבית |
| `labels.html` | **מדבקות שמות לתלמידים**: קובץ HTML אחד שעובד בדפדפן, בלי התקנות. כיתות, ייבוא מאקסל או CSV, דפים של 30 או 50 מדבקות במידות מדויקות בס״מ, סמל או תמונה, דף מלא לכל תלמיד ודפים כלליים, תצוגה מקדימה, PDF והדפסה. |
| `tasks-spec.html` | אפיון מערכת המשימות והתזכורות, כולל שאלות פתוחות |
| `tasks-setup.html` | הוראות התקנה של מערכת המשימות, צעד אחר צעד |
| `apps-script/Code.gs` | הקוד של מערכת המשימות (Google Apps Script) |
| `apps-script/App.html` | מסך הניהול של המשימות (Web App) |
| `apps-script/appsscript.json` | הגדרות הפרויקט (אזור זמן: ירושלים, גישה: רק אני) |

## הפעלת האתר
Settings ← Pages ← Source: **Deploy from a branch** ← Branch: `main` / `(root)` ← Save.

## מדבקות: הערות טכניות
- ה-PDF נוצר בדפדפן עצמו, בלי ספריות חיצוניות. כל דף נשמר כתמונה ברזולוציה של 200–300 DPI, בגודל A4 מדויק.
- ייבוא קובצי `xlsx` טוען את SheetJS מ-cdnjs. קובצי CSV או הדבקה מאקסל עובדים גם בלי אינטרנט.
- הנתונים נשמרים ב-localStorage של הדפדפן. כדי להעביר אותם למחשב אחר משתמשים ב"גיבוי" ואחר כך ב"שחזור".

## משימות: בקצרה
גיליון Google הוא מקור הנתונים. טריגר רץ כל 10 דקות ומפעיל את `tick()`, שעושה את הדברים הבאים:
- קולט משימות ממיילים שסומנו בתווית `משימה`.
- שולח מייל בוקר.
- שולח תזכורות מאוחדות לפי סדר: באיחור, מתקרבת, עדיפות, שעה, סוג.
- שולח סיכום יומי לפני סוף היום.

כפתורי "בוצע", "עוד שעה" ו"מחר" במייל עוברים דרך ה-Web App וחתומים ב-HMAC.
